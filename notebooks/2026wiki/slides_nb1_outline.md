### שקף 7 — מחלקת HebrewWikipedia: קריאת קוד
**סוג**: תיאוריה + הסבר קוד  
**כותרת**: `מחלקה (Class) — בניין-יסוד בתכנות מונחה-עצמים`

**תוכן**:
```python
class HebrewWikipedia:
    BASE_URL = "https://he.wikipedia.org/w/api.php"
    
    def get_category_members(self, name, depth=1): ...
    def get_page_links(self, title): ...
    def get_red_links(self, title): ...
```

**הסבר**:
- **class** = תבנית/מתכון שמצרפת נתונים + פונקציות יחד
- `self` = ה"אני" של המחלקה — הפניה לאובייקט עצמו
- `delay=0.15` = כבוד לשרת ויקיפדיה בין בקשות

**ייחוד**: הפונקציה `_request()` מתקנת אוטמטית רווחים → קווי תחתון בשמות הדפים

### שקף 13 — תיאוריית רשתות
**סוג**: תיאוריה  
**כותרת**: `🕸️ מה זו רשת (גרף)?`

**תוכן** (טבלה):
| מדד | הסבר | מה ויקיפדיה מגלה |
|-----|-------|-----------------|
| **In-Degree** | כמה ערכים מקשרים לכאן | "כמה פופולרי" |
| **Out-Degree** | כמה ערכים הערך מקשר אליהם | "כמה מחובר" |
| **PageRank** | אלגוריתם גוגל — חשיבות יחסית | "כמה סמכותי" |

**נקודה מרכזית**: ויקיפדיה = **גרף מכוון** — קישור מ-א ל-ב ≠ קישור מ-ב ל-א

📖 Barabási, *Network Science* (חינמי: networksciencebook.com)

- **אל תמתינו לכולם** — המשיכו כשרוב הסטודנטים סיימו
- תא 11 (שליפה) ותא 14 (בניית רשת) — הזהירו מראש שלוקח זמן
- השתמשו ב-DEMO_MODE=True אם האינטרנט לא מספיק מהיר

### שאלות נפוצות
- **"התא לא מגיב"** → Runtime → Restart runtime → Run all above
- **"שגיאה אדומה"** → קראו את השורה האחרונה של השגיאה
- **"אינטרנט איטי"** → `DEMO_MODE = True` בתא 10
